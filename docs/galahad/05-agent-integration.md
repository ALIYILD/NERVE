# Agent integration

The new MemoryGateway is a trusted-host facade; agents receive neither MemoryAuthority nor provider management primitives. Existing parallel_agents_v11, learn_mcp, agent registries and advisory JEV are preserved. No new agent registry, public MCP tool, executor or shell interface was added.

Executable integration is the authenticated MemoryService and the existing RecursiveEvolutionLoop objective using the gateway. Agent clients can query approved evidence and propose pending experiences via the Python reference client. The host independently reviews memory through decide; a submitted feedback record does not become verified knowledge.

The intended host cycle is identity → scope → gateway context → existing specialist → independent review → proposed memory. Model inference, automated hooks into all legacy agents, cross-agent shared caches and Clinical OS wiring remain proposed. The synthetic API returns evidence with review_required=true, not a clinical response. JEV has no path to override host permissions.
